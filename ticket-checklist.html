📋 Ticket Checklist

- [ ] What is the priority?
- [ ] What is the hard deadline?
- [ ] Who is the subject matter expert?
- [ ] Does the ticket needs breaking down?
- [ ] Does the ticket need a tech design?
- [ ] Should the tech design be reviewed?
- [ ] Does the ticket need an implementation plan?
- [ ] Does the ticket need a Test plan?
- [ ] Who writes the test plan? Who approves it?
- [ ] Does this ticket require special access/permissions to work on?
- [ ] What is the estimate for tech design+implementation plan+test plan?
- [ ] What is the estimate for the ticket's ACs?
- [ ] Is the ticket provided with everything necessary, ex: Figma designs, ACs, etc?
- [ ] Is this ticket complex enough to justify a spillover if necessary?
- [ ] Does this ticket require extensive testing as a separate task due to risks or complexity?
- [ ] When will the draft PR be ready for review?
- [ ] When will the final PR be ready for review?
- [ ] Does this need a separate ticket for FF creation?
